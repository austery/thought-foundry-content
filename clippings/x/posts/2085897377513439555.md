## Original text

<pre>给大家分享一个我在硅谷公司真实见到的 CPU 供不应求的情况，

大概从今年年初开始，公司里开始全面CPU 内核治理，部门有了指标，要节省内核数 15% 到 20%

新服务想申请资源？抱歉，没有。
旧服务流量上升想扩容？抱歉，排队

据我了解，这应该不是我们部门的独特处境。不少公司也有类似的情况，已经成为了一个共性的问题

穿越表象，找到其共同的原因，正是因为：Agent 时代已经不是 Chatbot 问答了，AI 多步骤、调用工具来回调度，对 CPU 的使用率呈指数级上升

CPU 在 Agent 时代发挥着更重要的作用。

我预计专门为 Agent 研发的定制 CPU 也会逐步贡献更多的利润，例如 Vera CPU from $NVDA ，结合和 GPU 的 co-design，让 token 产生得更便宜、调度更便宜、消耗更少、效率更高

因此看好 $NVDA $AMD ，基于目前的价格 ，两者我都有布局，个人更看好 NVDA，AMD情况更为复杂，两者我都有买

$AMD 拿到了十几份报告，还在建模当中。预计会发一篇分析文章

上个帖子有朋友问我研报在哪里能拿到，这个是我们跟各大券商企业版内部购买的</pre>
