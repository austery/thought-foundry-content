### 重返语文本质：超越应试与知识搬运

各位好，我是**邵鑫**。我是一个从小就比较喜欢读书的人，后来因为语文成绩好，就觉得继续读语文吧，高考时便去了**北京大学中文系**。当时我们高考可以填报三个志愿，我比较“头铁”，所有的志愿都只填了北大中文系。后来我在北大读了四年本科，又读了三年硕士，全部是在中文系完成的。从北大毕业之后，我现在在做的事情就是教大家读书。

此前我参加过一档电视节目叫《**超语文课**》，拿到了那个节目的总冠军，当时的称号是“最受欢迎语文老师”。这也是为什么在今天，很多人都会跑来问我说：“语文这个东西这么难学、这么无聊，你怎么会一直学了这么多年？而且你怎么会一直这么喜欢？”包括很多家长和学生都会觉得，在今天感觉语文好像越来越难学了。在以前我们小时候，语文学习似乎很直接：简单地看一看、背背课文，最多再做两套题就差不多了；为什么到了今天，大家突然感觉这套方法失效了？

于是很多人开始困惑：到底语文该怎么学？其实我一直有一个核心观点：如果你今天觉得我们的语文难学了，本质上不是语文变了，而是我们今天的考察方式越来越接近真正的语文了。

在这里其实存在一个根本问题：**当我们谈论语文的时候，我们到底在谈论什么？什么是语文？** 

当年**叶圣陶**先生曾精辟地解释过什么是语文：“发言为语，写下来为文。”也就是说，当我们口头上说出来、表达出来的语言，听到的就是“语”——今天我站在这里讲给各位听的，就是语；而当你把语言文字落实在纸面上，那就是“文”。我们平时读、写，都是在跟“文”打交道；我们听、说，都是在跟“语”打交道。

大家听到这里时有没有意识到：语文这门学科似乎很难被穷尽。因为只要是我们说出来的、听到的、读到的、写下来的，全部都是语文。那我们学语文的时候到底是在学什么？突然之间我们会发现，语文似乎无边无际、永远学不完。庄子当年说：“吾生也有涯，而知也无涯。”在今天，我们的学生生涯也是有限的，但语文的边界是无限的，那么语文到底应该怎么学？

首先我想告诉各位，在今天学语文，绝不是要求我们去死记硬背一堆死板的知识。在如今这个时代，知识已经丝毫都不稀缺了，甚至知识已经开始泛滥。如果我们再去向别人炫耀说“我学语文就是为了多认几个字、多记住一些文学常识”，这显然没有任何意义。**语文是一门基于根本能力的学科**，一切都要回归到语文的核心能力训练上来。

官方对语文学科核心素养有着非常明确的界定，主要包含四个关键维度：

1. **语言构建与运用**：语文是关于**语言文字**的学科。所有与语言文字相关的理解与表达，就是语文的基本面。学语文最基础的能力，就是培养你的语言文字水平。
2. **思维发展与提升**：语文是我们中国人的母语。我们在学语文时，本质上是在提升母语的**思维水平**。因为语言本身就是思维的底层代码，也是思维的边界。一个人用什么来思考？我们大脑中运行每一个念头时，依靠的都是语言。因此，语文本质上是在训练我们使用语言去思考的能力。试卷中那个经常让大家感到头疼的题型——**阅读理解**，其本质正是考察你如何运用语言去解决思维问题，追问“这个地方为什么这么写”、“为什么用这个词”，这是一种纯粹的思维推理。
3. **审美鉴赏与创造**：语言文字本身是一种极具魅力的艺术形式，就像音乐和绘画一样，只不过文学艺术是以语言文字作为媒介构成的。它本身具有独特的**审美美感**。有些考试题目常问“请你说说这个句子好在哪里”，很多学生由于缺乏真实的审美感知，只能去生搬硬套模板套路，就像某些男士在面对妻子询问“我今天穿得哪里好看”时，因为审美能力匮乏只能背诵套话一样。
4. **文化传承与理解**：语言文字只是表达工具，其终极目的是为了承载和表达我们丰富的内心世界与精神谱系。一切语文的内核，最终都指向人的心灵与**文化认同**。

这四个维度——语言、思维、审美、文化，就是我们学习语文、与语文打交道时根本上要去训练的核心能力。要判断自己是不是在真正学语文，只需看这件事是否有助于这四项能力的提升。

### 侦探推理式阅读：从被动翻阅到主动破案

当我把这四项能力解释给朋友们听时，他们往往会紧接着提出下一个疑问：“那我到底该如何培养这四项能力呢？”

我的回答始终只有一句话：“**你们要去读书。**”因为在阅读经典作品的过程中，我们既在与最高水平的语言文字打交道，也在与作者深邃的思维逻辑碰撞，同时还在沉浸式体验审美与文化的滋养。

但紧接着，大家又会冒出另一个普遍的痛点：“**为什么我读了很多书，我的阅读和写作还是不行？**”

这些年我一直在努力做一件事，就是希望让大家明白到底应该如何读书、读什么样的书。我倡导大家多读经典名著，因为只有经典作品的语言文字水平与思想深度才经得起推敲。同时，我特别希望各位明白：阅读绝不仅仅是浮于表面地看情节、记故事，也不仅仅是背诵知识点；**阅读本身是一场深度的思维与审美探索活动**。

平时我经常带大家读诸如《**史记**》、《**红楼梦**》、《**西游记**》、《**水浒传**》、《**三国演义**》、《**世说新语**》、《**论语**》以及鲁迅的《**朝花夕拾**》等经典著作。在学生时代，这些书往往很“招恨”——学校要求必读，但大家常常读不懂，觉得晦涩乏味。很多年轻人会想：“大好的青春年华，我为什么要读两千年前的人写的东西？”但这往往是因为你的阅读方法出了问题。

我在各种场合经常分享自己总结的一套阅读方法——**侦探推理式阅读法**。我从小就是一个侦探迷，非常喜欢看动画片《**名侦探柯南**》。我发现在读书的时候，读者的状态应当非常像一个赶赴案发现场破案的名侦探：
* **聚焦反常细节**：一个侦探来到案发现场，绝不会只看一眼“这里到底死没死人”，他首先会观察各种蛛丝马迹：为什么舞台的角落突兀地缺了一块？为什么这枚钉子会出现在不合常理的位置？为什么墙上的时钟指针显得诡异？在侦探眼里，一切皆是细节。
* **基于细节提出问题**：观察细节的目的是为了发现其中隐藏的矛盾与问题。在当今的**人工智能时代**，发现问题、提出深刻问题以及做出价值判断的能力至关重要，而单纯给出答案并不困难。侦探在捕捉到奇异细节后提出关键假设，真正的真相就潜藏在这些细节与推导背后。

侦探推理式阅读法包含三个核心要素：**好奇**、**共情**与**文化**。

### 好奇驱动：在文本缝隙中探寻作者隐秘意图

关于**好奇心**，常有人问我如何培养孩子的好奇心。我认为好奇心从来不需要刻意去“开发”，它是每个人与生俱来的天赋。一个婴幼儿在什么都不懂时会睁大眼睛四处张望、到处发问并刨根问底，这就是天生的好奇心。我们要做的是守住这份好奇心，不让它在成长过程中被应试和麻木所蒙尘。

在带领大家精读文本时，我常常会提出许多看似琐碎、实则关键的问题。

以中学经典课文《**红楼梦**》中“刘姥姥进大观园”的宴饮场景为例。刘姥姥为了讨贾母欢心，在王熙凤的安排下故意出丑逗乐，站起来高呼：“老刘，老刘，食量大如牛，吃个老母猪不抬头！”话音刚落，满堂大笑。

如果我们普通人写作文，往往一句“全场哈哈大笑”就草草带过。但作者**曹雪芹**却花费了极长的一整段文字，工笔细描了在场每一个人各不相同的笑态。此时，我们就需要像侦探一样提出好奇的追问：为什么每个人笑的方式截然不同？能不能把彼此的笑态调换？

```
刘姥姥出丑逗乐
       │
       ├─► 史湘云：撑不住一口饭喷出来 （豪爽直率、不拘小节）
       ├─► 林黛玉：笑岔了气，扶着桌子叫哎呦 （体弱娇怯、大家闺秀）
       ├─► 贾宝玉：滚到贾母怀里 （备受溺爱、恃宠而骄）
       ├─► 贾  母：搂着宝玉叫心肝 （核心权威、溺爱孙儿）
       ├─► 众丫鬟：躲出去蹲着笑 / 忍着笑上来服侍 （等级森严、规矩严苛）
       └─► 薛宝钗：全无笔墨描写 （城府极深、恪守端庄体统）
```

* **史湘云与林黛玉**：文中写史湘云是“撑不住，一口饭都喷了出来”；而林黛玉则是“笑岔了气，扶着桌子叫哎呦”。如果我们设想让林黛玉喷饭、让史湘云娇弱地扶桌叫哎呦，人物气质立刻就错位了。喷饭的细节刻画出史湘云毫无矫饰、英豪阔朗的假小子性格；而扶桌哎呦则精准展现了林黛玉体弱多病、内敛敏感的闺秀风范。
* **贾宝玉的“滚”**：在场有那么多晚辈孙辈（林黛玉、史湘云、贾宝玉、探春、迎春、惜春），为什么唯独贾宝玉可以“滚到贾母怀里”？因为这一动作背后揭示了残酷而真实的家族权力结构与情感偏向——贾宝玉是贾母唯一的“心肝宝贝”，只有他拥有肆无忌惮扑进最高统治者怀中的特权，其他晚辈若贸然效仿，极可能招致训斥。
* **丫鬟仆妇的克制**：底下伺候的丫鬟婆子们，有的“躲出去蹲着笑”，有的“忍着笑上来替姊妹们换衣裳”。笑本是人的自然生理反应，但在这个公府大家族中，森严的阶级秩序让底层仆从连笑的权利都被严格规训——不仅不能在主子面前放肆大笑，还得时刻保持服务姿态。
* **薛宝钗的“不写之写”**：曹雪芹写遍了在场所有的主要人物，唯独对**薛宝钗**只字未提。这是作者的疏漏吗？恰恰相反，在全场所有人笑得前仰后合之际，薛宝钗依然能够克制情绪、维持端庄稳重的仪态。曹雪芹用“不写”达成了对宝钗极深城府与克制性格的最高级塑造。

文学作品的精妙之处，往往不在于表面上讲了什么，而在于作者为何要采用这种特定的方式去讲。

这种对异常细节的好奇不仅适用于古代经典，同样适用于现代文学与日常生活。比如**鲁迅**在《**秋夜**》开篇写下的著名语句：“在我的后园，可以看见墙外有两株树，一株是枣树，还有一株也是枣树。”

小时候很多人会认为这是病句或废话，直接写“有两株枣树”岂不更简洁？直到有一次我出门旅行，突然发现自己没带钱，摸了摸左边的口袋是空的，再摸了摸右边的口袋发现也是空的。在那一瞬间，巨大的绝望与空虚感袭来，我立刻理解了鲁迅的笔法。如果只说“两边口袋都是空的”，情绪是平淡的；而当你把视线从一株树艰难地移向另一株树，发现依然是一株枯寂的枣树时，那种深入骨髓的孤独、无聊与绝望便通过语言的节奏被具象化了。

在流行文化中亦是如此：
* **周杰伦《星晴》**：“手牵手，一步两步三步四步望着天；看星星，一颗两颗三颗四颗连成线。”这种看似重复罗列的数数，精准传递了恋爱中年轻人雀跃、兴奋到近乎发痴的情绪状态。
* **林俊杰《背对背拥抱》**：“我们背对背拥抱，滥用沉默在咆哮。”有人会觉得“背对背如何拥抱”在物理上不合逻辑，但在情感逻辑中，这正是描写曾经亲密无间的恋人陷入倦怠与冷战时，那种同床异梦、近在咫尺却形同陌路的痛苦纠葛；而“沉默的咆哮”更是将无声的反抗与内心的撕裂展现得淋漓尽致。

### 共情与审美：在字句停顿中体会意境

侦探阅读法的第二个关键是**共情**（Empathy），它直接决定了读者的**审美鉴赏能力**。审美的底层逻辑是将心比心——能够敏锐捕捉并体验到文字创作者所灌注的细腻情感。

很多读者阅读速度过快，像旅游打卡一样只求赶进度、看结局，往往错过了一路最美的风景。真正的阅读必须慢下来。

在《**水浒传**》中有一段描写“九纹龙”**史进**与“跳涧虎”**陈达**交锋的比武场面。很多读者遇到打斗场面往往一目十行扫过，但若慢下来细读，会发现施耐庵运用了一整套精妙绝伦且绝不重样的武打动词：

> “两个斗到深涧……卖个破绽，往心窝里搠来；把腰一闪，荷枪颠入怀里；轻舒猿臂，款扭狼腰，只一斜……”

更精彩的细节在于史进生擒陈达的瞬间。史进武艺远高于陈达，作者在描写他将陈达擒下马鞍时，使用了一个极具张力的动词：

> 史进轻舒猿臂，把陈达轻轻**摘**离了马鞍。

我们通常只会说摘花、摘果、摘树叶，何时见过“摘”一个全副武装、手持兵刃的壮汉？一个看似轻描淡写的“摘”字，以极具举重若轻的反差感，瞬间将史进高出对手数个量级的武艺威压刻画得入木三分。如果读者不懂得在此类字眼上驻足共情与推敲，自然无法真正体会到汉语锤字炼句的美感。

```
│ 《水浒传》史进擒陈达      │ “摘”离马鞍              │ 举重若轻，以摘花果之词写生擒壮汉，显绝顶武艺 │

```

再看家喻户晓的唐诗——**孟浩然**的《**春晓**》：

> 春眠不觉晓，处处闻啼鸟。  
> 夜来风雨声，花落知多少。

这首诗绝非简单描写春天景致的童谣，其背后蕴藏着极深沉的生命体验：
* **“不觉晓”与“知多少”的闭环**：全诗开篇写“不觉”——在极致舒适美好的春夜安眠中，人完全感知不到天明是何时悄然而至的；而结尾写“花落知多少”——回想起昨夜隐约的风雨，美丽的花朵不知飘落了多少，春天正在不知不觉间悄然流逝。
* **生命哲思**：当我们真正沉浸在生命的美好之中时，往往很难觉察这种美好是何时降临的，更难以觉察它在何时正在流逝。这种体悟提醒我们：**必须倍加珍惜眼下所拥有的春光与美好事物**。这种直击心灵的情感共振，才是阅读古诗词的真正意义。

### 文化化人：破除认知滤镜与人生执念

侦探阅读法的第三个维度是**文化**。所谓“文化”，其本质是“**以文化人**”——通过阅读促成自我的认知跃迁与精神蜕变。阅读经典最终必须回归到我们自身的人生课题中。

在高中经典文言文《**战国策·邹忌讽齐王纳谏**》中，齐国重臣**邹忌**身高八尺有余，容貌昳丽。一天早晨他照镜子自省，问妻子自己与齐国美男子城北徐公相比谁更美。
* **妻子的回答**：“君美甚，徐公何能及君也！”（结合了极度赞叹与强烈反问，语气最为笃定）
* **妾的回答**：“徐公何能及君也！”（仅保留单层反问，语气稍逊）
* **门客的回答**：“徐公不若君之美也。”（平铺直叙的陈述句，语气最为平淡）

当邹忌亲眼见到徐公并自知远不如对方时，他开始深入反思三者给出虚假赞美的背后动机：
1. **妻子偏爱他（“私我也”）**：出于深厚的爱意，爱会自带极强的滤镜，因此其赞美最为主观而坚定。
2. **妾畏惧他（“畏我也”）**：出于对主从尊卑地位的恐惧，不得不顺从逢迎。
3. **门客有求于他（“有求于我也”）**：出于对实际利益的图谋，其附和带着显而易见的敷衍与工具性。

这段经典的心理洞察为我们提供了穿越复杂人际迷雾的智慧：**永远不要盲目相信外界给予你的所有评价**。赞美或贬损的背后往往掺杂着爱、恐惧与利益的滤镜。更深层的人生启示在于：**利益可以掩盖真相，恐惧可以压制利益，而爱能够战胜恐惧**。

阅读的最高境界是将书中的智慧转化为自己分析世界、表达见解的思想武器。写文章绝非为了应付考试凑齐字数，而是为了就某个真实的人生议题清晰表达出你由内而生的独立见解。

再看《**西游记**》中九九八十一难的最后一难——通天河晒经。师徒四人历经十四年十四万八千里的千难万险，历尽降妖除魔的艰辛取得真经，却在通天河落水，将经书捞起在石头上晾晒时，撕破了经尾，导致经文残缺不全。唐僧为此痛心疾首，而**孙悟空**却劝慰道：“天地本不全，经文残缺，正应了不全之理，非人力所能为也。”

这一看似残酷的结局蕴含着极高深的佛家智慧与生命哲学：**一个人克服的困难越多、能力越强，就越容易陷入追求绝对完美的执念之中**。而《西游记》的终局正是要借这残缺的经卷，彻底破除修行者对“完美”的执妄，教会我们接纳人世间的不完美。

### 结语：在AI时代守护人类核心竞争力

在人工智能高速发展的今天，AI能够以极快的速度为我们提供海量标准答案与信息检索。然而，机器终究无法替代人类的两大核心能力：
1. **提出深刻、敏锐且有价值问题的能力**；
2. **在海量复杂的信息与答案面前做出独立审美与道德判断的能力**。

带着好奇去发现反常细节，带着共情去体会文字与人性的温热，带着文化的自觉去探寻人生的答案——这就是我们今天面对经典所应持有的姿态。

最后，我想用《西游记》中孙悟空劝解唐僧的一句话与各位共勉。当年面对遥遥无期的西行之路，唐僧一度感到迷茫与焦躁，孙悟空对他说：

> “师父不必挂念，少要心焦，且自放心前进，还你个**功到自然成**。”

只要我们踏踏实实深入语言文字的肌理，真正与经典同行，语文的核心素养与思想深度自会在日积月累中水到渠成。
